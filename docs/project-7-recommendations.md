# Project 7 - Recommendation System and Experimentation

Implements weighted behavioral feedback, popularity/content/collaborative candidate signals, cold-start fallback, consumed-item filtering, explainable weighted ranking, Precision@K, Recall@K, NDCG@K, catalog coverage, category diversity, deterministic sticky experiment assignment, conversion outcomes, and two-proportion significance analysis.

Exercises: construct two similar users; test cold start; add dislikes; alter ranking weights; calculate each metric by hand; simulate uplift and distinguish statistical from practical significance. Discuss candidate generation versus ranking, implicit-feedback bias, position bias, leakage, exploration/exploitation, delayed rewards, diversity/novelty, segment metrics, and online/offline disagreement.
